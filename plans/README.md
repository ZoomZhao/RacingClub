## 执行顺序与边界

先提取会话边界和共用场景，再修复状态/手势，再处理绘制与状态展示，最后完整回归、独立审查差异、生成固定签名Release。Android与iOS执行者各自拥有文件范围，共享场景由Android方创建、两端解释相同语义。修复在独立worktree验证后再纳入主工作目录。

禁止修改80关题面、参考答案、合法拓扑、原始参考照片、固定发布身份；不新建后端，不引入WebView，不恢复教学/试跑/全部拼板入口。复用已有美术素材，不重做用户已确认风格。Android默认0°放置与竖向预览是不同的既定语义。

验证基线：22项JS通过，16项Kotlin通过，Android Lint无错误（37项现存警告，包括版本建议、旧资源与非阻断样式项）。最终验证：26项JS、37项Debug/37项Release JVM单测、22项Android原生界面用例全部通过；Swift全80关核心回放、3项共享场景及平台专项检查通过；完整arm64源码编译/链接通过。签名压缩Release覆盖安装通过外部UI验证。详见 [验收摘要](../docs/validation/native-review-014.json)、[APK核验](../docs/validation/android-release-014.json) 和 [Release UI核验](../docs/validation/android-release-014-ui.json)。CI会运行同样的规则/会话/编译门禁，推送后另确认执行结果。


## 补充审查与修复

同模型独立补审覆盖浏览器控制器、规则验证工具、静态服务、资料脚本、离线求解与发布验证，原始结论见 [补充报告](opus-5.5-supplement-20261023.md)。原生审查的只读结论与产品已决定的取舍分开保留。

- 静态服务先判断规范化后的公开文件与真实路径，拒绝编码路径和符号链接越界；仅 index/src/public/design 可服务，默认监听127.0.0.1。测试只用临时无敏感内容的文件，没有读取真实私有文件。
- 浏览器排行榜切换/关闭弹窗和隐藏→可见时，只在没有开放模态且页面可见时恢复计时和判胜；最终启动跑动前再次检查条件。
- 浏览器恢复时丢弃坏的存档根与无效成绩项，保留有效记录；坏项不再使页面初始化失败。
- 发布UI核验明确拒绝Python优化模式，保证断言不能被静默移除后写出通过报告。
- iOS本地构建每次清理生成的.app目录，删除清单中的资源不会残留在下一次打包里。

## 最终验证中的修正

- 新增拼板无障碍节点移到马儿节点下层，避免读屏树遮掉马儿状态；托盘清理子节点并把描述、状态、文字和点击操作集中在一个节点，读屏与真实触摸均经Android实测。
- 拖拽测试每项清理自己的进度与成绩，避免从前项存档恢复多余拼板；即时UI缓存断言改为等待实际状态。未删除用例或放宽产品规则。
- 后台恢复用例允许ActivityScenario返回时已进入本次结算，仍验证后台计时冻结、无提前记分、恢复后自动通关且仅一条成绩。

验证范围限于API35模拟器（含620dp与1.35倍字号）、macOS 无界面 Swift测试与iOS SDK编译。没有实体手机性能基准，也没有iPhone/iOS模拟器UI与VoiceOver验收，不将代码层对齐冒充设备验收。
