# 游戏页与操作按钮

本轮按用户最新要求使用内置 ImageGen 重新设计。完整提示词、输入用途和原始输出位置见 [imagegen-prompt-v1.json](imagegen-prompt-v1.json)，设计稿见 [imagegen-reference-v1.png](imagegen-reference-v1.png)。设计稿用于材质和控件造型参考，运行界面由 Compose/Canvas 与 SwiftUI/Canvas 原生绘制。初版设计稿中的右侧旋转位置源于上轮误解，已按用户纠正移到左侧棋盘上的选中拼板附近；当前布局以 v2 原生截图为准。

- 左侧取消页头与任务占用，棋盘按可用高度和原始比例尽量放大，保留边界入口与箭头空间。
- 任务、挑战编号、难度、计时、排行榜与帮助集中在右上。目标自动折返换行，包含重复编号，完整显示且不滚动。
- 右侧不再有整块白色背景卡片；单块拼板、目标条、必要的文字小标签保留轻量背景，保证场景上的可读性。
- 拼板按题目中首次出现的顺序去重排列，仅展示本关需要的拼板，最多支持两排十块。移除全部库存入口及弹窗。
- 旋转和移回关联的是左侧棋盘上的已放置拼板。选中后显示左转 90°、右转 90°、移回三个按钮，优先放在拼板上下空位并避让其他拼板；无空位时贴入当前拼板，横板底部横排、竖板右侧纵排，保留当前编号可见，避免遮挡邻板。拖动、跑动或选中未放置的拼板时隐藏。
- 操作控件统一为奶油色按钮面、铜色细边、白色内高光和轻微下沿；按下有反馈。右侧底部仅撤销、提示、重置三个图标，提示采用暖金色。
- 支持从托盘拖入棋盘，也支持直接拖动棋盘上已有拼板。拖动保留抓取点，显示随手指移动的半透明拼板及吸附落点。
- 落点有效时绿色描边；叠放时琥珀色描边并指出将覆盖的编号，允许松手提交；越界时红色描边并提示边界。松手才提交，一次成功拖拽为一步；失败、取消、原位放回不增加步数，不污染撤销记录。
- 旋转始终成功；底边或右边空间不足时按最小距离向棋盘内部平移，允许覆盖其他拼板。操作位置仍跟随棋盘上的选中拼板。
- 拼板按底到顶顺序渲染，遮挡处只显示顶层；可见顶层的琥珀色“叠 N”标记与右侧持续提示显示仍有下层。点击右侧编号可将对应拼板置顶，移回顶层会露出下层；撤销与存档保留堆叠顺序。
- 右侧棋盘中拼板使用浅绿底、绿边、勾选与绿色“已放置”标签，被遮挡时使用叠层图标和琥珀色“被遮挡”标签，避免仅靠细小勾选判断。本次沿用已有 ImageGen 设计的材质、配色和原生控件，无新增位图素材。
- 成功跑动期间，右下操作区替换为沿用奶油铜边样式的“跳过动画”，点击立即结算；跨障时对应编号缩放 14%、琥珀光晕持续 600ms，已跨过目标保留金色外环；圆牌内部只绘制数字，外环与光晕留在牌外，重复编号逐次处理。
- 拖动期间暂缓自动通关判定；允许临时叠放，但所有重叠消除后才由实际路线规则决定跑动及通关。
