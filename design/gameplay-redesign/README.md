# 游戏页与操作按钮

本轮按用户最新要求使用内置 ImageGen 重新设计。完整提示词、输入用途和原始输出位置见 [imagegen-prompt-v1.json](imagegen-prompt-v1.json)，设计稿见 [imagegen-reference-v1.png](imagegen-reference-v1.png)。设计稿用于材质和控件造型参考，运行界面由 Compose/Canvas 与 SwiftUI/Canvas 原生绘制。

- 左侧取消页头与任务占用，棋盘按可用高度和原始比例尽量放大，保留边界入口与箭头空间。
- 任务、挑战编号、难度、计时、排行榜与帮助集中在右上。目标自动折返换行，包含重复编号，完整显示且不滚动。
- 右侧不再有整块白色背景卡片；单块拼板、目标条、必要的文字小标签保留轻量背景，保证场景上的可读性。
- 拼板按编号升序，仅展示本关需要的拼板，最多支持两排十块。移除全部库存入口及弹窗。
- 依用户后续修改，旋转已从棋盘移到右侧选中拼板卡片下方。双向 90° 按钮通过小尖角关联该卡片，靠近两侧时整体向内收。未放置的拼板也能先旋转再拖入。
- 操作控件统一为奶油色按钮面、铜色细边、白色内高光和轻微下沿；按下有反馈。底部仅移回、撤销、提示、重置四个图标，提示采用暖金色。
- 支持从托盘拖入棋盘，也支持直接拖动棋盘上已有拼板。拖动保留抓取点，显示随手指移动的半透明拼板及吸附落点。
- 落点有效时绿色描边；重叠时红色描边并指出冲突的拼板编号；越界时提示边界。松手才提交，一次成功拖拽为一步；失败、取消、原位放回不增加步数，不污染撤销记录。
- 拖动期间暂缓自动通关判定，放下后继续由实际路线规则决定跑动及通关。
