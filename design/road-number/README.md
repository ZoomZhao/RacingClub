# 路面编号

使用内置 ImageGen，以原生十块满盘截图为参考设计；提示词完整保存在 [imagegen-prompt-v1.json](imagegen-prompt-v1.json)，生成结果为 [imagegen-reference-v1.png](imagegen-reference-v1.png)。图稿用于视觉参考，应用内的编号仍由 Android Canvas / SwiftUI Canvas 原生绘制。

- 编号位于奶油色道路的空段，避开障碍横杆；旋转后文字保持正向。
- 移除高饱和圆底和投影，改为浅奶油底、细沙金边、深绿粗体数字。颜色只占数字下方的短线，继续对应障碍颜色。
- 棋盘字号由每格的 0.20 提升为 0.22；前景 `#214334`、实色底 `#fff0d2`，对比度约 9.7:1。
- 竖向托盘沿用路面编号，移除卡片角上的重复圆牌。预览数字最低 11dp/pt，包含双位数 10；不随缩略图无限缩小。
- 满盘时优先选择操作按钮之外的道路段，必要时靠近同一条道路的边缘，编号仍留在本块拼板内。叠放提示也参与避让。
- 右上方任务序列保持彩色圆牌，维持顺序识别与跨障动效。

Android 实际截图：满盘 `android-full-board-v1.png`，选中 `android-selected-v1.png`。它们是十块容量验证摆法，不是第 76 关答案。

几何与可读性检查覆盖 10 块 × 4 个方向、20–48dp 预览单元和 52–100dp 棋盘单元。iOS 同步实现并通过核心检查和 SDK 编译，尚无设备运行时的视觉验收。
