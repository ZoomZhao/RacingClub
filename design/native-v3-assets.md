# 原生棋盘视觉与方向素材 v3

使用内置 `image_gen.imagegen`，以已确认设计稿和本轮选定素材为参考生成。14 张透明 PNG 原件保存在 `public/assets/native-v3/`，对应原生资源在 Android `drawable-nodpi/*_v3.png`。完整提示词、每张图的生成原路径和项目路径见 [native-v3-imagegen-prompts.json](native-v3-imagegen-prompts.json)。

- 马儿：东、东南、南、西南、西、西北、北、东北八个独立视图；没有骑手，减少手机尺寸下的细碎信息。原生端依据路线切线选图，不旋转侧面位图。
- 终点门：上、右、下、左四个独立视图，按 A–F 所属棋盘边缘选择并定位。门保持立柱向上，不把正面图横转或倒置。
- 起终点：绿色起点旗和赭红棋格终点旗标牌，文字仍由原生绘制。棋盘边框用相同颜色的字母标识，完整中文说明放在棋盘下方，避免占住拼板路线。
- 围栏：六个开口两端各有收尾柱，横杆连接柱中心；字母标识避开柱帽。
- 排版：取消小字号继承的大行高，统一中文字距；挑战卡片调整内边距、段落间距、标题与难度标记。排行榜使用对齐的原生行列。
- 箭头：障碍顺序和下一关使用固定尺寸的原生矢量箭头，保持中心与基线对齐。

原始生成图不裁切、不重编码。原生加载时降采样，并仅调整绘制用的透明边界矩形，保持运行内存与棋子锚点稳定。
