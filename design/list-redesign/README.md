# 关卡列表挑战牌设计

最初使用内置 ImageGen 生成设计参考，完整提示词见 `imagegen-prompt-v1.json`，原图见 `imagegen-reference-v1.png`。后续按用户要求移除其中的拼板缩略图，仅沿用徽章与牌面风格。当前实现见 `android-home-clean-progress.png`。

- 列表页移除右上角帮助入口，品牌行缩小，为关卡留出空间。游戏页仍保留原有玩法入口。
- 五档难度使用有雕刻边缘的段位牌，罗马数字徽章、细叶饰与金色描边；选中项使用对应难度深色底。
- 关卡使用奶油色内嵌面与木质倒角、黄铜固定钉，突出编号、进度与成绩；不显示拼板或棋盘图片。
- 品牌标题放在左列，右侧标题与它同行，避免右侧被整页品牌行向下挤。关卡按钮使用剩余高度，增加点击面积。
- 未开始显示进入箭头，进行中显示时钟，已完成显示绿勾并展示真实最佳时间；所有状态读取既有存档。
- 默认横屏每档 16 张牌完整展示。放大字体时关卡牌增高，列表可垂直滚动，难度切换仍直接可见。
- Android 使用 Compose 和原生 Canvas；SwiftUI 同步牌面、徽章与按压反馈，仍需 iOS 设备验收。
